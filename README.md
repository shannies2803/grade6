# Philip’s Grade 6 Theory

Self-study ABRSM music theory app for Philip, as a single-page web app (`index.html`), plus printable PDFs.

- `index.html`: the app (works offline once loaded; progress is saved in the browser on each device).
- `downloads.html`: page listing the PDFs.
- `pdfs/`: Book 1: From Grade 5 (Days 1–4), Book 2: Four-part harmony (Days 5–17), Book 3: Harmonising melodies (Days 18–24), Book 4: Composing (Days 25–31), Book 5: Score questions (Days 32–40), Book 6: Practice papers and exam (Days 41–48), Practice papers 1–6 (with marking keys), Question bank (with answers and model answers).

Deploy: static site, publish directory is the repo root (no build step).

# Philip’s Grade 6–7 Theory

Self-study ABRSM music theory app for Philip, as a single-page web app (`index.html`), plus printable PDFs.

- `index.html`: the app (works offline once loaded; progress is saved in the browser on each device).
- `downloads.html`: page listing the PDFs.
- `pdfs/`: Book 1: From Grade 5 (Days 1–4), Book 2: Four-part harmony (Days 5–17), Book 3: Harmonising melodies (Days 18–24), Book 4: Composing (Days 25–31), Book 5: Score questions (Days 32–40), Book 6: Practice papers and exam (Days 41–48), Practice papers 1–6 (with marking keys), Question bank (with answers and model answers), Reference book, Grades 6–7 (figures, progressions, part-writing rules, Grade 7 chords, suspensions, orchestra, terms), Grade 7 book 1: chords and figuring a bass (Days 49–63), Grade 7 book 2: suspensions and composing (Days 64–75), Grade 7 book 3: scores and practice papers (Days 76–88), Grade 7 practice papers 1–3 (with marking keys), Grade 7 question bank (with answers and model answers).

Deploy: static site, publish directory is the repo root (no build step).
